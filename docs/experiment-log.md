## 关键教训

1. **清洗器是质量瓶颈**: 半角标点不切分 → 长段整段丢弃(800k文档→693句)。
   修复 = 非汉字串替换为换行边界, 语料利用率×6。
2. **词表必须与解码词典同源**(sc.dict 导出), jieba 词表/交集词表都更差。
3. **剪枝 0 0 1 无副作用**(E1 vs v1), 保留。
4. **域覆盖决定分桶成绩**: 字幕→口语, CWT2→新闻/职场, 游记→旅行。
5. 人名地名天花板受**本质歧义**限制(张伟/张维柱), 需用户模型解决(Phase 2)。
